# QuickPOS Landing Page

[![QuickPOS CI/CD Pipeline](https://github.com/MahadAsh/QuickPOS-Final/actions/workflows/ci.yml/badge.svg)](https://github.com/MahadAsh/QuickPOS-Final/actions/workflows/ci.yml)

A professional, responsive Point of Sale landing page built with pure HTML, CSS (Glassmorphism), and PHP.

## Features

- Modern Glassmorphism UI
- PHP Backend Form Validation
- Fully Automated CI/CD Pipeline via GitHub Actions
- Custom PHP Testing Framework
